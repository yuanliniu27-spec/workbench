如何添加到主屏幕并收到提醒

电脑（推荐 Chrome / Edge）

  1. 用 Chrome 或 Edge 打开本页（必须是 HTTPS）。
  2. 点击地址栏右侧的「安装」或「添加到桌面」图标。
  3. 在弹窗中允许通知。也可在本页点「允许通知」，再点「发送测试通知」检查。

小米手机（含 17 Pro Max / HyperOS）

  1. 用 Chrome 打开本页（系统浏览器对 PWA 通知支持较弱）。
  2. 右上角菜单 →「添加到主屏幕」或「安装应用」，确认添加。
  3. 从主屏幕图标打开工作台，点「允许通知」，并发送一条测试通知。
  4. 如没有横幅或声音：打开系统「设置」→「通知与控制中心」/「通知」→ 找到 Chrome 或「工作台」→ 打开通知、横幅、锁屏通知、声音。
  5. 建议在「设置 → 应用设置 → 应用管理 → Chrome（或工作台）」里把省电策略设为「无限制」，并允许自启动，避免被杀掉后无法提醒。

无法提供官方小米 Mi Push。后台提醒依赖浏览器能力：页面打开时最稳；已添加到主屏幕的 Android Chrome 可能通过周期后台同步补提醒；若浏览器支持 Notification Triggers 也会提前排期。进程被系统强制冻结时，仍可能漏提醒。请以测试通知验证本机是否真正弹出。
